# Data Directory Guide

This repository expects input datasets to be placed inside the `data/` directory using the folder layout described below.

## Expected Dataset Folders

- `data/data_Fluized/`
- `data/data_Compacted/`
- `data/data_QuickMap/`
- `data/data_train_classifier_2.0/`

## Typical File Types

Depending on the workflow, the toolkit may use:

- `.npz` depth maps
- `.mat` MATLAB files
- `.xyz` point clouds

## Naming Conventions

Most scripts assume naming schemes such as:

- `fluized_<index>.npz`
- `compacted_<index>.npz`
- `depthMap_<index>.xyz`
- `plane_<index>.npz`

If you use different names, prefer one of the following:

- run the workflow in **single-file mode**,
- set an explicit prefix where supported,
- or adapt the dataset naming to the repository conventions.

## QuickMap / LROC note

For QuickMap / LROC workflows, users must also provide:

- `xres`
- `yres`
- `zres`
- `scale`
- `z_shift`

`z_shift` is used as a vertical offset to align the imported topography with the intended lunar geodetic zero reference.

## GitHub Recommendation

Large scientific datasets should generally **not** be committed directly to the repository unless you intentionally manage them with one of the following strategies:

- Git LFS
- a reduced example dataset for demonstration purposes
- an external download source documented in the main README

By default, output generated by the scripts is written to:

output/
