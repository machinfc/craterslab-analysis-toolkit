# Security Policy

## Reporting a Vulnerability

If you discover a security-related issue in this repository, please do not publish it immediately in a public issue.

Instead, contact the repository maintainer privately and include:

- a description of the issue,
- the affected files or workflow,
- reproduction steps if relevant,
- and any proposed mitigation.

## Scope

This repository is a scientific scripting toolkit and is not intended as a security-sensitive production service. However, vulnerabilities involving dependency management, file handling, or unsafe execution behavior should still be reported responsibly.

## Third-Party Dependencies

Some risks may originate in upstream dependencies such as `tensorflow`, `keras`, or `craterslab`. When appropriate, also report issues to the upstream maintainers.
